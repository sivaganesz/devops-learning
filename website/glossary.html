DevOps Glossary

A comprehensive A-Z reference of essential DevOps terminology and concepts.

Use this glossary as a quick reference while navigating through the course. Click on the phase links to jump directly to the detailed lesson covering the concept.

A B C D E F G H I J K L M N O P R S T V W

A

API Server
The central control plane component of Kubernetes that exposes the Kubernetes API. It is the front end for the Kubernetes control plane.
Learn in Phase 09: Kubernetes Basics →
Argo CD
A declarative, GitOps continuous delivery tool for Kubernetes that automatically syncs the cluster state to match the state defined in a Git repository.
Learn in Phase 14: GitOps with Argo CD →
Artifact
A byproduct of the CI process, such as compiled binaries, tarballs, or test reports, which can be stored and used in later stages.
Learn in Phase 07: CI/CD Pipelines →
Auto-sync
A feature in GitOps tools like Argo CD that automatically applies changes pushed to the Git repository to the target Kubernetes cluster.
Learn in Phase 14: GitOps with Argo CD →
Availability Zone (AZ)
Distinct locations within a cloud provider's region that are engineered to be isolated from failures in other zones.
Learn in Phase 15: AWS EKS & Cloud Services →

B

Bash
The Bourne Again SHell, a command processor that typically runs in a text window where the user types commands that cause actions.
Learn in Phase 01: Linux Basics →
Blob (Git)
The object type in Git used to store the contents of a file.
Learn in Phase 06: Git Version Control →
Branch
An independent line of development in Git, allowing you to work on features isolated from other developers.
Learn in Phase 06: Git Version Control →

C

CIDR
Classless Inter-Domain Routing, a method for allocating IP addresses and IP routing.
Learn in Phase 15: AWS EKS & Cloud Services →
CI/CD
Continuous Integration and Continuous Deployment/Delivery. The practice of automating the building, testing, and deployment of software.
Learn in Phase 07: CI/CD Pipelines →
ClusterIP
The default Kubernetes Service type that exposes a service on a cluster-internal IP, making it only reachable from within the cluster.
Learn in Phase 09: Kubernetes Basics →
CMD (Dockerfile)
The Dockerfile instruction that provides defaults for an executing container.
Learn in Phase 04: Building Docker Images →
ConfigMap
An API object in Kubernetes used to store non-confidential data in key-value pairs, which can be consumed as environment variables or config files by Pods.
Learn in Phase 09: Kubernetes Basics →
Container
A lightweight, standalone, executable package of software that includes everything needed to run an application.
Learn in Phase 03: Docker Fundamentals →
Control Plane
The part of the Kubernetes cluster that manages the worker nodes and the Pods in the cluster. Includes the API server, scheduler, and controller manager.
Learn in Phase 09: Kubernetes Basics →
cron
A time-based job scheduler in Unix-like operating systems.
Learn in Phase 02: Linux Processes →

D

Deployment
A Kubernetes API object that manages a replicated application, providing declarative updates to Pods and ReplicaSets.
Learn in Phase 09: Kubernetes Basics →
Desired State
The state you specify for a system (like in Kubernetes or Terraform), which the system will continually try to achieve and maintain.
Learn in Phase 09: Kubernetes Basics →
Distroless
Docker images that contain only your application and its runtime dependencies, lacking package managers, shells, or other typical OS programs.
Learn in Phase 04: Building Docker Images →
Docker
A platform designed to help developers build, share, and run modern applications using containers.
Learn in Phase 03: Docker Fundamentals →
Docker Compose
A tool for defining and running multi-container Docker applications using a YAML file.
Learn in Phase 05: Docker Compose →
Dockerfile
A text document containing all the commands a user could call on the command line to assemble a Docker image.
Learn in Phase 04: Building Docker Images →
Drift
The divergence between the actual state of infrastructure and the expected/desired state defined in code (e.g., in Terraform or GitOps).
Learn in Phase 14: GitOps with Argo CD →

E

EC2
Amazon Elastic Compute Cloud, a web service that provides secure, resizable compute capacity in the cloud.
Learn in Phase 15: AWS EKS & Cloud Services →
ENTRYPOINT
A Dockerfile instruction that configures a container that will run as an executable.
Learn in Phase 04: Building Docker Images →
Environment Variable
A dynamic-named value that can affect the way running processes will behave on a computer.
Learn in Phase 01: Linux Basics →
etcd
A consistent and highly-available key value store used as Kubernetes' backing store for all cluster data.
Learn in Phase 09: Kubernetes Basics →
Executor
The environment (like a Docker container or shell) where a GitLab Runner executes the CI/CD job.
Learn in Phase 07: CI/CD Pipelines →

F

FROM instruction
The first instruction in a valid Dockerfile, initializing a new build stage and setting the Base Image.
Learn in Phase 04: Building Docker Images →

G

Git
A free and open source distributed version control system designed to handle everything from small to very large projects with speed and efficiency.
Learn in Phase 06: Git Version Control →
GitOps
An operational framework that takes DevOps best practices used for application development such as version control, collaboration, compliance, and CI/CD, and applies them to infrastructure automation.
Learn in Phase 14: GitOps with Argo CD →
Grafana
An open source analytics and interactive visualization web application that provides charts, graphs, and alerts for the web when connected to supported data sources like Prometheus.
Learn in Phase 17: Grafana Dashboards →

H

HPA (Horizontal Pod Autoscaler)
A Kubernetes feature that automatically updates a workload resource (such as a Deployment), with the aim of automatically scaling the workload to match demand.
Learn in Phase 20: Scaling & Performance →
Helm
The package manager for Kubernetes, helping to manage Kubernetes applications.
Learn in Phase 12: Helm Package Manager →
Helm Chart
A collection of files that describe a related set of Kubernetes resources, packaged by Helm.
Learn in Phase 12: Helm Package Manager →

I

IAM
Identity and Access Management, a framework of policies and technologies for ensuring that the right users have the appropriate access to technology resources.
Learn in Phase 15: AWS EKS & Cloud Services →
Image
A read-only template with instructions for creating a Docker container.
Learn in Phase 03: Docker Fundamentals →
Image Layer
Modifications to an image, represented as stacked read-only filesystems. Every instruction in a Dockerfile creates a layer.
Learn in Phase 04: Building Docker Images →
Ingress
An API object that manages external access to the services in a cluster, typically HTTP/HTTPS.
Learn in Phase 11: Kubernetes Networking →

J

Job (CI)
A single set of instructions to be executed in a CI/CD pipeline, such as running tests or building code.
Learn in Phase 07: CI/CD Pipelines →

K

Kubernetes
An open-source container-orchestration system for automating computer application deployment, scaling, and management.
Learn in Phase 09: Kubernetes Basics →
kubelet
An agent that runs on each node in the cluster, making sure that containers are running in a Pod.
Learn in Phase 09: Kubernetes Basics →
kubectl
The Kubernetes command-line tool, allowing you to run commands against Kubernetes clusters.
Learn in Phase 09: Kubernetes Basics →

L

Liveness Probe
A diagnostic performed periodically by the kubelet on a Container to determine if it is running correctly. If it fails, the container is killed and restarted.
Learn in Phase 09: Kubernetes Basics →
Load Balancer
A device or service that acts as a reverse proxy and distributes network or application traffic across a number of servers or Pods.
Learn in Phase 11: Kubernetes Networking →

N

Namespace
A mechanism to isolate groups of resources within a single Kubernetes cluster.
Learn in Phase 09: Kubernetes Basics →
NAT Gateway
Network Address Translation Gateway, allowing instances in a private subnet to connect to services outside your VPC but external services cannot initiate a connection with those instances.
Learn in Phase 15: AWS EKS & Cloud Services →
Node
A worker machine in Kubernetes, which may be a virtual or physical machine, depending on the cluster.
Learn in Phase 09: Kubernetes Basics →
NodePort
A type of Kubernetes Service that exposes the Service on each Node's IP at a static port.
Learn in Phase 09: Kubernetes Basics →

P

PersistentVolume (PV)
A piece of storage in the cluster that has been provisioned by an administrator or dynamically provisioned using Storage Classes.
Learn in Phase 10: Kubernetes Storage →
PersistentVolumeClaim (PVC)
A request for storage by a user, which can request specific size and access modes.
Learn in Phase 10: Kubernetes Storage →
Pipeline
A set of automated processes that allow developers and DevOps professionals to reliably and efficiently compile, build, and deploy their code.
Learn in Phase 07: CI/CD Pipelines →
Pod
The smallest and simplest Kubernetes object. A Pod represents a set of running containers on your cluster.
Learn in Phase 09: Kubernetes Basics →
Prometheus
An open-source systems monitoring and alerting toolkit originally built at SoundCloud.
Learn in Phase 16: Prometheus Monitoring →
PromQL
Prometheus Query Language, used to select and aggregate time series data in Prometheus.
Learn in Phase 16: Prometheus Monitoring →

R

Readiness Probe
A probe to determine whether a container is ready to respond to requests.
Learn in Phase 09: Kubernetes Basics →
Reconciliation
The process by which controllers watch the state of your cluster, and make or request changes where needed to move the current state towards the desired state.
Learn in Phase 14: GitOps with Argo CD →
Registry
A storage and content delivery system, holding named Docker images, available in different tagged versions.
Learn in Phase 08: Container Registries →
Release (Helm)
An instance of a chart running in a Kubernetes cluster.
Learn in Phase 12: Helm Package Manager →
ReplicaSet
A Kubernetes object whose purpose is to maintain a stable set of replica Pods running at any given time.
Learn in Phase 09: Kubernetes Basics →
Runner (GitLab)
An application that works with GitLab CI/CD to run jobs in a pipeline.
Learn in Phase 07: CI/CD Pipelines →

S

Secret
An object that contains a small amount of sensitive data such as a password, a token, or a key in Kubernetes.
Learn in Phase 09: Kubernetes Basics →
Service (K8s)
An abstract way to expose an application running on a set of Pods as a network service.
Learn in Phase 09: Kubernetes Basics →
SIGTERM
A signal sent to a process to request its termination, allowing the process to clean up and exit gracefully.
Learn in Phase 02: Linux Processes →
Stage (CI)
A logical grouping of jobs in a CI/CD pipeline (e.g., build, test, deploy).
Learn in Phase 07: CI/CD Pipelines →
StorageClass
A way for administrators to describe the "classes" of storage they offer, dynamically provisioning storage on request.
Learn in Phase 10: Kubernetes Storage →
Subnet
A logical subdivision of an IP network.
Learn in Phase 15: AWS EKS & Cloud Services →
Systemd
A suite of basic building blocks for a Linux system, notably providing a system and service manager that runs as PID 1 and starts the rest of the system.
Learn in Phase 02: Linux Processes →

T

Terraform
An infrastructure as code tool that allows you to build, change, and version infrastructure safely and efficiently.
Learn in Phase 13: Infrastructure as Code →
TLS
Transport Layer Security, a cryptographic protocol designed to provide communications security over a computer network.
Learn in Phase 11: Kubernetes Networking →

V

VPC
Virtual Private Cloud, a secure, isolated private cloud hosted within a public cloud, such as AWS.
Learn in Phase 15: AWS EKS & Cloud Services →
Volume (Docker)
The preferred mechanism for persisting data generated by and used by Docker containers.
Learn in Phase 03: Docker Fundamentals →

W

Worker Node
A node in a Kubernetes cluster where containerized applications (Pods) are scheduled and run.
Learn in Phase 09: Kubernetes Basics →
