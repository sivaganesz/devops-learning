🔗 The TaskFlow Project

TaskFlow Project

Our Running Example

Throughout this curriculum, we will use the TaskFlow application. It is a real-world 3-tier web application consisting of:

  • Frontend: React + Vite (port 5173 dev, builds to static files)
  • Backend: NestJS on Node.js (port 3000)
  • Database: PostgreSQL (port 5432)

We will start by running it on a single Linux VM, then containerize it with Docker, build automated CI/CD pipelines in GitLab, deploy it to AWS EKS (Kubernetes) using Helm and Argo CD, and finally monitor it with Prometheus and Grafana.
